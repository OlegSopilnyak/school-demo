== Intro
The *Module* is implementing main *Business Logic* of the *Application*. The *_Ingress Module_* _stuff_ is communicating with it through *BusinessFacade* set. The implementation in module is executing particular *Action* in order to implement the *Application*'s feature. Each *Action* is executing in the *ActionContext*.

.*IngressModule's* The Communication Through Stuff
include::../puml/class-diagrams/ActionContextStuff.puml[]
The Controller of *ingress module* launches *Action* through the particular *business facade* according to the feature's Domain.

.Business Facades by *Domain Features*
[%collapsible]
====
*Note!* +
The *actionId* values are declared in the particular facade. +
The *Action* is executing using *doActionAndResult(actionId , actionParameters)* using particular *Facade*.
